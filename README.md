# Video Generator PWA

Minimal PWA shell for a video-generation interface.

## Current state

- Responsive HTML/CSS/JS
- Installable PWA manifest
- Service Worker
- Offline application shell
- Local persistence of prompt and settings
- Online/offline status
- Google Veo placeholder
- No API keys in the client
- No backend yet

## GitHub Pages

Upload the repository and enable GitHub Pages from the repository's Pages settings.

The site must be served over HTTPS for Service Worker/PWA features.

## Next step

Connect a real Veo provider through a secure Local Node/API gateway. Do not put a production API key into `app.js`.
